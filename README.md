# SyncSpace

Collaborative document editor for developers.
Real-time editing, AI assistance, voice rooms.

## Stack
- Backend: Node.js, Express, Sequelize, PostgreSQL
- Frontend: React, Vite, TailwindCSS, Tiptap
- Realtime: Socket.io
- Voice: WebRTC (PeerJS)
- AI: Claude API
